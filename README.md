## 👋 Hello!

I'm Ersan, a fullstack developer in The Netherlands. I build web apps and tools, specializing in Microsoft Azure and .NET technologies. I love learning new tech and sharing knowledge.

## 🧩 Background

I first became interested in programming while creating mods for games from the 90s. Trying to understand and modify how games behaved, led me to learn assembly and experiment with reverse engineering.

What started as a hobby quickly turned into a passion for programming, and eventually into a career in software development. Today I enjoy building tools, web applications, and systems that simplify workflows, automate tasks, and solve real-world problems.
